=== Config


Default configuration


==== Parameters

[%header%autowidth.spread]
|===
| Name | Type | Description | Default Value | Required
|Name | String | The name for this configuration. Connectors reference the configuration with this name. | | *x*{nbsp}
| Connection a| <<Config_Connection, Connection>>
 | The connection types that can be provided to this configuration. | | *x*{nbsp}
| Default service name a| String |  service.name for spans when the listener or publish operation doesn't set its own |  mule-app | {nbsp}
| OTLP endpoint a| String |  OTLP/HTTP traces endpoint of your OpenTelemetry Collector |  http://localhost:4318/v1/traces | {nbsp}
| Tracing enabled a| Boolean |  When false, no spans are exported (trace context is still propagated if present) |  true | {nbsp}
| Name a| String |  The identifier of this element used to reference it in other components |  | *x*{nbsp}
| Expiration Policy a| <<ExpirationPolicy>> |  Configures the minimum amount of time that a dynamic configuration instance can remain idle before the runtime considers it eligible for expiration. This does not mean that the platform will expire the instance at the exact moment that it becomes eligible. The runtime will actually purge the instances when it sees it fit. |  | {nbsp}
|===
